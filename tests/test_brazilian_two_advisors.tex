  \chapter{Algoritmos e listagens}
  \label{cap:algo}

  Um algoritmo via \texttt{algorithm2e} usando os macros pt-BR registrados
  pela classe (\verb|\Para|, \verb|\Enquanto|):
  \begin{algorithm}[H]
    \caption{Soma trivial de um vetor}
    \KwIn{vetor $v$ de tamanho $n$}
    \KwOut{soma $s$}
    $s \leftarrow 0$\;
    \Para{$i \leftarrow 1$ \KwTo $n$}{
      $s \leftarrow s + v[i]$\;
    }
    \KwRet $s$\;
  \end{algorithm}

  Uma listagem Python (\texttt{listings}), via o estilo \texttt{python}
  registrado pela classe:
  \begin{python}
def soma(v):
    s = 0
    for x in v:
        s += x
    return s
  \end{python}
