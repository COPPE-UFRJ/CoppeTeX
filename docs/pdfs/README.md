# PDFs do site CoppeTeX

Cópias dos documentos distribuídos em `dist-coppe/manuais/` e
`dist-poli/manuais/`, publicadas pelo GitHub Pages para leitura direta.
Não editar estes PDFs: depois de regenerar as distribuições, atualizar as
cópias correspondentes nesta pasta. Os documentos compartilhados da classe
UFRJ são copiados de `dist-coppe/manuais/`.
